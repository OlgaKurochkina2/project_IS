# АИС «FoodWay» — репозиторий проекта внедрения

## Название и назначение
АИС «FoodWay» — веб-платформа доставки еды для ООО «FoodWay». Система автоматизирует приём заказов, оплату и доставку: каталог партнёров и меню, корзина, статусы заказа, работа курьеров и уведомления. Репозиторий хранит документацию, исходные конфигурации, тесты и управленческие материалы проекта внедрения.

## Структура папок
```
project_IS/
├── docs/          # проектная документация (требования, архитектура)
├── src/           # код и конфигурации (Django, Nginx)
├── tests/         # тестовые материалы (план тестирования, smoke-тест)
├── management/    # управленческая информация (план, риски)
└── README.md      # описание проекта
```

## Как запустить / использовать
1. Клонировать: `git clone <URL репозитория>`.
2. Документы читать в `docs/` и `management/`.
3. Конфигурация веб-сервера находится в `src/nginx.conf`, зависимости — в `src/requirements.txt`.
4. Тесты: `python -m unittest discover tests`.
