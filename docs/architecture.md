# Архитектура АИС «FoodWay»

Трёхзвенная схема: клиент (браузер) → Nginx (балансировщик, 80/443) → Django (сервер приложений, порт 8000) → PostgreSQL (порт 5432).

| Узел | Назначение |
|------|-----------|
| Nginx | Приём HTTPS, перенаправление HTTP→HTTPS, проксирование |
| Django | Бизнес-логика: заказы, каталог, роли (RBAC) |
| PostgreSQL | Хранение данных, ежедневный backup, копия вне сервера |

Внешние интеграции (HTTPS REST): платёжный сервис, сервис карт, сервис уведомлений.
